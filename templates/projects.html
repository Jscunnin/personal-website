My Projects

The EspGH

This project consisted of setting up a local network of 2 ESP8266 micro controllers and a Raspberry Pi in order to read and control the temperature of a room, using relays, in order to care for plants. I did this using a MQTT system with the Raspberry Pi as the broker. Then in order to see the data I made a custom website using Flask with python that would display information such as the current temperature, the current humidity, and it would provide graphs of the temperature and humidity over time.

API implementation

I have used API's in some of my smaller projects. Some of these consisted of using an IP information API inside of my website for the espGH in order to monitor the traffic through the website. I have also attempted to use weather API's to control whether the heating or cooling system was used for the espGH but unfortunately I did not have the hardware available to implement this.

Rockets!!(UB Seds)

I helped work on drivers in c to communicate with a BMI 088 over SPI on a rocket in order to help control the thrust of the rocket. I learned a lot of valuable skills here including working with git, working with imbedded systems, working in a larger team, and coding in c.
